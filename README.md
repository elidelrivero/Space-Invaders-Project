# Spacial Blast 🚀

Un videojuego estilo arcade desarrollado en C++ que recrea la clásica experiencia de Space Invaders. Este proyecto fue desarrollado con un enfoque principal en la **programación concurrente**, utilizando hilos (threads) para gestionar de manera independiente y simultánea los elementos del juego.

## Tecnologías utilizadas

* **Lenguaje:** C++
* **Gráficos:** Raylib
* **Entorno de Desarrollo:** Visual Studio Code (VS Code)
* **Conceptos clave:** Programación concurrente, manejo de hilos (multithreading), sincronización.

## Cómo ejecutar el juego

Este repositorio está listo para funcionar (plug-and-play). Ya incluye las librerías necesarias de Raylib y los ajustes de configuración de VS Code, por lo que no necesitas configurar rutas ni descargar dependencias externas.

**Requisitos previos:**
* Tener instalado [Visual Studio Code](https://code.visualstudio.com/).
* Tener instalada la extensión de **C/C++** de Microsoft en VS Code.
* Contar con un compilador de C++ instalado en tu sistema (como MinGW o GCC).

**Pasos:**
1. **Descarga el proyecto:**
   * Simplemente haz clic en el botón verde **"<> Code"** arriba y selecciona **"Download ZIP"**. Luego, extrae la carpeta.
2. **Abre el proyecto:** Abre Visual Studio Code, ve a `Archivo > Abrir Carpeta...` (File > Open Folder...) y selecciona la carpeta que acabas de descargar.
3. **Ejecuta el juego:** * Presiona `F5` o ve al menú superior y selecciona `Run > Start Debugging`. 
   * VS Code leerá automáticamente la configuración incluida en el repositorio, compilará el código con la librería de Raylib y abrirá la ventana del juego.

## Controles

* **Movimiento:** Flechas Izquierda / Derecha (o A / D)
* **Disparo:** Barra Espaciadora
