Space Blast / Space Invaders

Un videojuego estilo arcade desarrollado como proyecto universitario para aplicar conceptos de programación concurrente.

## Tecnologías utilizadas
* C++
* Raylib
* Hilos (Threads) para la concurrencia

## Características principales
* Movimiento de enemigos independiente usando hilos.
* Sistema de colisiones.
